# 旅途片刻 —— 量產 SOP

跟「財商筆記本」共用同一套技術管線（video-autopilot-kit），走的是框架**原生設計**的
`silent_vlog_maker` 生產線，不是 `shorts_autopilot`（財商用的抽象圖解那條）。

## 跟財商筆記本的關鍵差異

**財商筆記本**：內容是抽象觀念，b-roll 可以用程式生成（圖表、色塊、字卡動畫）代打，
效果可以接受，因為觀念本身不靠真實畫面佐證。

**旅途片刻**：內容是真實的家人朋友出遊畫面，**必須用真實素材**（手機拍的照片/影片），
程式生成的色塊/圖表完全沒有意義。

## ⚠️ 隱私鐵則（每次製作前必檢查，不是選項）

- 只保留使用者自己家人朋友願意公開的人
- **背景/合照裡如果有其他不相關的人（尤其是小孩）清楚入鏡，必須裁切或模糊處理**
  —— 使用者自己家人同意公開，不代表背景路人或其他人的孩子也同意
- 拿到一批新素材時，先過一遍這條規則，篩選/處理過才進入製作流程
- 如果不確定某個畫面裡的人是不是使用者的家人朋友，直接問使用者，不要自己假設

## 固定規格

- 頻道：`旅途片刻`，人設見 `profiles/brand.md` + `profiles/voice.md`
- 尺寸：1080x1920，平台 `ig_reels`
- 配色：暖黑 `#14100D` + 柿子橘 `#F4863D`（字卡/資訊條用，不影響真實畫面本身的顏色）
- 對應模組：`src/silent_vlog_maker/shorts_vertical.py` 的 `build_one_short()`
- `place` = 地點/活動名稱、`what` = 一句話這是什麼場合、`addr` = 常駐資訊條（可放頻道口號）
- 字級/字幕規則：**跟財商筆記本不同**（那邊是 150px 大字置中）——旅途片刻走真實人像畫面，
  大字置中常常擋臉，改成統一「白底藍字、字級適中、置於下方」，見下方「字卡樣式覆寫」

## ⚠️ 字卡樣式覆寫（每次重新 clone 框架都要重做，因為改的是框架原始碼，不會隨 git 保留）

`video-autopilot-kit/src/silent_vlog_maker/shorts_vertical.py` 的 `_HEADER` 裡，
把 `ADDR` 那一行整行換成：

```
Style: ADDR,Noto Sans TC,80,&H00FF881E,&H00FFFFFF,&H00000000,-1,0,0,0,100,100,0,0,3,4,0,5,40,40,0,1
```

（PrimaryColour 藍 `&H00FF881E`、OutlineColour 白 `&H00FFFFFF` ——**ASS 裡 BorderStyle=3 的
不透明方框顏色是 OutlineColour，不是 BackColour**，這是踩過的坑，改錯欄位會變成黑底不是白底）

同一個檔案的 `COLOR_VARIETY` dict 要加一行藍色：
```python
'b': r'{\c&H00FF881E&}',   # 藍 RGB 1E88FF
```

**所有字卡的 `caps` 都用 `kind="addr"` + `color="b"`**（不要用 `kind="main"`，那個是財商筆記本
用的大字置中樣式，在真人照片上會直接蓋到臉）。`_ADDR_POS` 沿用原本的 `pos(540,1390)`，
位置已經夠低，不會擋到大部分照片的人臉，不用再改。

## ⚠️ 照片轉片段：裁切填滿 vs 完整顯示（會裁到臉，踩過的坑）

`scale=...force_original_aspect_ratio=increase,crop=...`（裁切填滿）在**照片長寬比跟
9:16 差很多**時（尤其正方形合照、多人橫向排開的照片），會把兩側或上下裁掉一截 ——
如果剛好有人站在照片邊緣，臉會被裁掉一半。已經真實發生過一次（4 人合照，最左邊的人臉被切）。

**判斷原則**：照片裡如果有**兩人以上**、或明顯不是「單人置中特寫」，優先用「完整顯示」
（`force_original_aspect_ratio=decrease,pad=1080:1920:(ow-iw)/2:(oh-ih)/2:color=0x14100D`，
上下或左右留黑邊，但保證所有人都在畫面裡）。只有單人置中的特寫照片才用裁切填滿。
做完每一支都要抓幾格出來人工看一遍，確認沒有人被裁到臉。

## 素材需求

1. 手機拍的出遊照片/影片片段（家人朋友的真實互動片刻）
2. 地點/活動名稱、一句話說明這是什麼場合（真實資訊）

## 流程

1. 使用者提供素材 → **先過隱私鐵則檢查**（裁切/模糊背景中其他人）→ 丟進
   `videos/_INBOX/vlog/<N>/`
2. 照片轉成短片段（`ffmpeg -loop 1 -i xxx.jpg -t <秒數> ...` 靜態或加 Ken Burns 推近效果）；
   影片用 `normalize_to_portrait()` 轉正成 9:16
3. 手動排 `caps=[(start,end,[(text,color)],kind)]` 與 `segs=[(clip,in,dur)]`
   （這條線沒有自動 scan+plan 生成器，需要手動排時間軸）
4. 呼叫 `build_one_short(segs, caps, bgm, out, vol=0.42)` 產出成片
5. 人工看過一次，確認：(a) 字幕跟畫面對得上 (b) 隱私鐵則有沒有漏檢查
