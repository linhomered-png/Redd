# 財商筆記本 —— 發布計畫(手動版)

自動發文（Windsor.ai → Instagram）目前卡在平台端權限限制，無法使用。
以下是目前唯一可行、且不需要任何額外設定的發布方式。

## 一、帳號建立（尚未做，第一步）
1. 申請一個新的 Instagram 帳號，用戶名建議：`caiseonotes` / `wealth.notes.tw` 這類，
   避免跟現有帳號混淆
2. 切換成「專業帳號」→「創作者」（Settings → Account type and tools → Switch to professional account）
3. 連結一個 Facebook 粉專（IG 商業帳號需要綁定才能之後有機會走自動化）
4. 大頭貼：用品牌色（深黑 + 螢光黃）做一個簡單的文字 logo（例如「筆」字或「財筆」二字）

## 二、每支片的發布 SOP
1. 從 `videos/_INBOX/shorts/<N>/_out/short_<N>_xxx.mp4` 抓出成片
2. 打開 Instagram App → 建立 Reels → 上傳這支影片（不要重新剪，直接用成片）
3. **Caption 撇寫規則**（呼應 voice.md）：
   - 第一行：重複 hook 句（跟影片開頭字卡一樣），例如「有錢人不急著花錢」
   - 空一行
   - 2-3 句簡短補充（可以比字卡再多解釋一點點，但不要超過 3 句）
   - 結尾固定：`追蹤 財商筆記本，每天記一個新觀念`
   - Hashtag（3-5 個即可，不要塞爆）：`#財商 #理財觀念 #複利 #財富自由 #投資新手`
4. 發布時勾選「同步分享到 Facebook 粉專」（如果 IG 有連結粉專，這個勾選可能自動幫你把 FB 也發了 —
   實測後在 `MY-PROGRESS.md` 補記錄，看是否真的有效）
5. 若 FB 沒有自動同步，就把同一份 caption + 影片手動貼到粉專，發一次 FB 原生貼文

## 三、發布節奏建議
- 新頻道階段：**先求穩定頻率，不求爆量**。建議一週 2-3 支，測試哪個切角互動較好
- 每支發布後，48 小時內回頭看留言/分享數，記錄在 `algorithm.md`（累積幾支後才有意義）
- 不要因為第一支沒反應就停 —— 至少累積 8-10 支才能看出風格是否對觀眾有效
