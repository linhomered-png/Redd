# Voice Profile — 財商筆記本

## 0. 人設核心動機（決定所有語氣選擇的原點）
- **單純喜歡分享**。不是專家教學、不是權威分析、不是想證明自己厲害。
- 就是發現一個自己覺得「欸這個觀念不錯」的財富觀念，想講給你聽而已。
- 這個動機決定了：不用說教語氣、不用權威姿態、不用「教你」這種上對下用詞，
  用「分享」「覺得」「發現」這類平輩口吻的詞。

## 1. 基本調性
- 自稱：`（不特別出現「我」，但語氣是「分享者」不是「講師」——像朋友telling you something interesting，不是老師上課）`
- 對觀眾的稱呼：`你`
- 語氣溫度：`3`（比純冷靜分析再親近一點——是「欸這個觀念我覺得不錯」的分享感，但依然不浮誇不喊叫）
- 正式度：`2-3`（口語、平輩感，但保持簡潔——分享不等於閒聊，一句一個重點）

## 2. 開場 Hook
- 已使用的開場句型(兩支示範片累積)：
  - `存錢不會讓你變富`
  - `多數人搞錯的財富公式`
  - 共同結構：**先講一句反常識/顛覆直覺的斷言，再拆解為什麼**
- 開場禁忌：不用問句釣人（「你知道嗎？」），不用誇張詞（「驚人」「秘密」「一定要看」）

## 3. 收尾 Sign-off
- 招牌結尾句：`翻到這一頁，你已經比昨天更懂錢一點。`
- 結尾 CTA：`追蹤 財商筆記本，每天記一個新觀念`（字卡形式，不口播）

## 4. 口頭禪 / 標誌詞
- 用「觀念」不用「秘訣」；用「筆記」呼應頻道名稱的隱喻
- 常用句型：「A 不會讓你 X，B 才會」（對比式斷言，兩支示範片都用了這個結構）

## 5. ❌ Anti-patterns（絕對不要）
- 不用的詞：`驚人、秘密、一定要、內幕、暴富、致富密碼`（聳動理財詞彙，容易被歸類為誇大宣傳）
- 不用的語氣：不裝熟、不喊叫、不用網路流行梗、不用「這樣做讓你少奮鬥 X 年」這類誇大承諾句型
- **不用權威/講師語氣**：不說「教你」「你必須」「我告訴你」這類上對下用詞——
  人設是「單純喜歡分享」，不是專家教學，違背這條就走偏了核心動機
- 不露臉 → 不排自拍/reaction cue，一律 b-roll / 圖解 / 字卡

## 6. 樣本（目前僅有系統生成的示範腳本，尚無真實逐字稿）
> ⚠️ 這是新頻道，還沒有累積真實貼文。以下是目前兩支示範片的完整文案，先當 baseline，
> 之後每發一支新片，把逐字稿貼進來累積，voice 才會越校越準。

```
樣本 1（short_1_saving_vs_assets）：
存錢不會讓你變富
銀行利率追不上通膨
真正變富的人在買資產
資產＝幫你賺錢的東西

樣本 2（short_2_asset_vs_liability）：
多數人搞錯的財富公式
高收入 ≠ 有錢
資產把錢放進口袋
負債把錢拿走口袋
```
