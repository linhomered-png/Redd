執行「旅途片刻」生活紀錄短影音生產流程。人設已定案，見
`video-workflows/旅途片刻/profiles/brand.md` 與 `voice.md`；完整規格見
`video-workflows/旅途片刻/PRODUCTION-SOP.md`，照著做。

## ⚠️ 隱私鐵則（每次都要先做，不是選項）

這個頻道**會露臉**（跟財商筆記本、原本的旅途一口都不同）。使用者提供的素材是真實家人朋友
的出遊照片/影片。**開始製作前必須先確認**：
1. 畫面裡的人是使用者自己的家人朋友，且知情願意公開
2. 背景/合照裡如果有其他不相關的人（尤其是小孩）清楚入鏡，**先裁切或模糊處理**再使用
3. 不確定畫面裡某人是誰，直接問使用者，不要自己假設可以用

## ⚠️ 跟 /財商影片 的關鍵差異

這條線走 `src/silent_vlog_maker/`，**不是** `shorts_autopilot.py` 那條抽象圖解線。
核心差異：**這條線必須要有使用者提供的真實素材，不能像財商筆記本那樣用程式生成抽象圖表代打。**

如果使用者還沒提供素材，先跟使用者要真實的出遊照片/影片，以及地點/場合的一句話說明。
不要在沒有真實素材、或隱私檢查沒過的狀況下生成內容。

## 準備環境（每次 session 第一次跑才需要）

1. 檢查 scratchpad 有沒有 `video-autopilot-kit`；沒有就 `git clone https://github.com/Hao0321/video-autopilot-kit.git`
2. 把 `video-workflows/旅途片刻/profiles/*.md` 複製進 `video-autopilot-kit/profiles/`
3. **套用字卡樣式覆寫**（每次重新 clone 都要重做一次，不會隨 git 保留）：
   照 `PRODUCTION-SOP.md`「字卡樣式覆寫」章節，修改
   `src/silent_vlog_maker/shorts_vertical.py` 的 `ADDR` style 那一行 + `COLOR_VARIETY` 加藍色
4. 讀 `video-workflows/旅途片刻/PRODUCTION-SOP.md`，照裡面的流程執行

## 拿到素材（且隱私檢查通過）後的流程

1. 素材丟進 `videos/_INBOX/vlog/<N>/`；真人動態影片（非靜態字卡類）可視內容用
   `setpts=0.5*PTS` 加速，讓節奏更活潑
2. 照片轉短片段：一般近景用裁切填滿；**多人合照/寬景照用「完整縮放塞入＋留黑邊」**，
   確保所有人都在畫面裡不被裁掉；影片用 `normalize_to_portrait()` 轉正 9:16
3. 排 `segs` 時間軸 + `caps`（place=地點/活動、what=場合說明）。
   **字卡一律 `kind="addr"` + `color="b"`**（白底藍字、下方、不擋臉 —— 不要用 `kind="main"`）
4. `build_one_short()` 產出成片
5. 人工檢查：字幕跟畫面對不對得上、有沒有擋到任何人的臉、隱私鐵則有沒有漏檢查
6. SendUserFile 交付，並更新片單記錄
