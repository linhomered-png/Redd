執行完整的「財商筆記本」短影音生產流程。人設與規則全部已定案，不用重新問使用者，
除非缺了關鍵資訊（例如完全沒給主題）才問。

## 0. 準備環境（每次 session 第一次跑才需要）

1. 檢查 scratchpad 裡有沒有 `video-autopilot-kit` 資料夾；沒有的話：
   ```bash
   git clone https://github.com/Hao0321/video-autopilot-kit.git
   ```
2. 把 `video-workflows/財商筆記本/profiles/*.md` 複製進
   `video-autopilot-kit/profiles/`（這是持久化在這個 repo 裡的人設設定，不要重新設計）
3. 讀一遍 `video-workflows/財商筆記本/PRODUCTION-SOP.md` —— 裡面是這個工作流的完整規格
   （配色、字型路徑、字級上限、分段時長、字幕頻率、素材製作鐵則），全部照做，不要自己另外決定
4. 確認 `ffmpeg`、`python3`（含 Pillow + numpy）可用；沒有就先裝

## 1. 想觀念

根據使用者給的主題（$ARGUMENTS），或如果使用者只說「做一支新的」沒給主題，
自己想一個財商觀念，套用 `voice.md` 裡的 hook 句型（「A 不會 X，B 才會」／「多數人搞錯的 XX」）。
人設核心是「單純喜歡分享」，不要寫成講師/權威語氣。

## 2. 準備素材（純視覺，絕不燒錄文字）

- Hook / Outro 背景：直接複用專案裡已有的 `clip_hook.mp4` / `clip_outro.mp4`
  （深黑底 + 螢光黃色塊動畫，已經有現成的，不用重畫）
- 如果觀念需要圖解（對比/趨勢/流程類）：用 Pillow 畫純圖形示意圖（不要畫完整句子，
  圖例標籤 2 字以內即可），存 PNG，再用 SOP 裡的 ffmpeg 指令轉成 9 秒的 Ken Burns 動態片段

## 3. Scan → 編輯 `_plan.py` → 同步 `_work/` → Build

嚴格照 `PRODUCTION-SOP.md` 的「完整流程」章節執行，尤其注意：
- 內容段落 `dur` 手動改成 `8.0`（scan 預設給的 4.8 太短）
- `caps_by_seg` 寫滿 **6 條**（1.5 倍字幕密度）
- 每條字幕**最多 2 行**，超過就換一句更短的講法，絕對不要 3 行（會壓到底部資訊條）
- 改完素材後記得 `cp` 覆蓋 `_work/` 裡的正規化副本，不然 build 用的是舊檔
- BGM 長度要蓋過影片總長（目前 `assets/bgm/calm/soft_pad.mp3` 是 28 秒，19.6 秒影片夠用；
  如果之後把影片拉更長，記得配樂也要跟著變長）

## 4. 檢查 + 交付

1. 打開 `_out/_qa/CAPTION_match.jpg`，確認每一格只有一則訊息、沒有重疊或裁切
2. 有問題就回第 3 步調整，不要交付有排版問題的版本
3. 用 SendUserFile 把成片傳給使用者，簡短說明這支片的觀念是什麼
4. 更新 `video-workflows/財商筆記本/PUBLISH-PLAN.md` 的片單表格（新增這支片的狀態列）

使用者這次給的主題／需求：$ARGUMENTS
