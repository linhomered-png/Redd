# 團購批發商招募短影片 — 文案腳本

給對象：批發商 / 供應商（希望透過團購平台出貨、擴大訂單量）
影片長度：建議 30 秒（也附 15 秒精簡版）
用途：可直接照分鏡自行拍攝，或用照片＋文字卡搭配本專案（Redd 照片轉影片工具）剪成影片。

## 30 秒完整版

| # | 時間 | 畫面建議 | 字卡（畫面文字） | 旁白 / 字幕 |

## 15 秒精簡版（適合投放廣告）

1. (0-4s) 倉庫貨架畫面 → 字卡：**「貨賣不完？」**
2. (4-9s) 手機團購搶購畫面 → 字卡：**「上千團媽幫你賣」**
3. (9-13s) 後台訂單暴增畫面 → 字卡：**「零上架費，7天翻3倍」**
4. (13-15s) Logo + QR code → 字卡：**「掃碼加入」**

---

## 使用建議

- **拍攝/素材**：若手邊沒有實拍畫面，可用倉庫、商品、手機介面截圖等靜態照片，搭配上表文字卡與轉場，用本專案（Redd）的「照片轉影片」功能直接合成 MP4。
- **背景音樂**：建議選節奏明快、正向的商業/勵志風格配樂，長度需 ≥ 30 秒（Redd 支援自動循環音樂配合影片長度）。
- **文字卡**：每張字卡建議停留 3-5 秒，重點數字（如「7 天」「3 倍」「零上架費」）可加大字級或變色強調。
- **CTA（最後一張）**：務必放上聯絡方式（QR code / LINE 官方帳號 / 電話），並停留至少 3 秒方便觀眾截圖。

---

## 可替換的訴求重點（依實際數據調整）

- 訂單量／成長倍數（如「7 天訂單翻 3 倍」）
- 合作供應商數量（如「已有 200+ 批發商合作」）
- 免費/低成本上架（「零上架費」「免庫存」）
- 審核與上架速度（「24 小時快速審核」）
- 平台觸及的團媽/揪團主數量（「上千位團媽同時推廣」）

> 以上數字為範例，請依實際情況替換成真實數據，避免誇大不實的招募宣傳。
